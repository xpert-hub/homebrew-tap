# Typewriter for Homebrew

Typewriter is a private Markdown editor for journalists, for Macs with Apple silicon (macOS 13 or later).

```bash
brew install --cask xpert-hub/tap/typewriter
```

Update with `brew upgrade --cask typewriter`; remove with `brew uninstall --cask typewriter` (add `--zap` to also delete settings, licences and downloaded AI models; your stories are never touched).

Typewriter isn't notarized by Apple yet. The first time you open it, macOS asks: go to System Settings → Privacy & Security and click "Open Anyway".

The releases in this repository hold the app's `.dmg` files. They are published automatically from each tagged release.
